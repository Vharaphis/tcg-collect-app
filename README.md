# 🃏 TCGCollectApp

A multiplatform app to manage your complete Trading Card Game (TCG) collection, regardless of the franchise.

---

## 📌 Description

**TCGCollectApp** is designed to provide TCG collectors with a centralized space to manage all aspects of their trading card hobby — all within a single app, available across multiple devices.

## 📦 Installation

### Requirements

- Node.js >= 18.x
- Yarn or npm
- React Native CLI or Expo CLI
- Android Studio or Xcode for emulator/simulator
- iOS/Android physical device for real-world testing (optional)

### Clone & Install

```bash
git clone https://github.com/yourusername/TCGCollectApp.git
cd TCGCollectApp
npm install
```

### Start the app

```bash
npm start
# or with Expo
npx expo start
```
